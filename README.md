# Jennifer Wu: Portfolio

Source for [jwu0216.github.io](https://jwu0216.github.io). I build tools and interactive systems for artists and users: Unity and Unreal Engine 5 tools, HLSL shaders, rendering optimization, and artist-facing generative AI tooling.

- **Monte Carlo path tracer:** [jwu0216/monte-carlo-path-tracer](https://github.com/jwu0216/monte-carlo-path-tracer)
- **Recall, AI memory assistant for iOS:** [jwu0216/Recall](https://github.com/jwu0216/Recall)

## Run locally

```bash
npm install
npm start
```

Pushing to `main` builds the site and deploys it to GitHub Pages (`.github/workflows/deploy.yml`).
